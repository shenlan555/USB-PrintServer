软件说明：
 服务端-----安装在打印机需要分享出去的电脑上
 客户端-----它仅仅辅助为需要去连接打印机的电脑快速安装

1.4.3
 首个开源版本（MIT 许可），源码与编译好的服务端/客户端见 GitHub Releases
 服务端提供完整 IPP 打印服务（RFC 8010/8011，端口 631），GUI 模式与服务模式同时启用
 PDF 渲染使用 PDFium（BSD-3-Clause，运行时动态加载 pdfium.dll）
 IPP 能力直接读取打印机驱动：彩色/纸张/双面/分辨率，
   针式机连续纸、彩色机不再被当成黑白 A4；改动后需删除客户端队列重装才生效
 输出纸张跟随 PDF 页面尺寸（DEVMODE 自定义纸张），横向页面按横向纸输出
 大幅面按面积限制渲染分辨率（单页上限 6000 万像素）；
   位图锐化改为三行缓冲原地处理，单页内存峰值减半
 驱动按 Windows 已装驱动包（DriverStore）整包抓取，兼容 Win7/Win2008
 驱动包带 SHA256 清单与 RSA-2048 签名，客户端验签不通过则拒绝安装
 /api/driver 增加 HMAC-SHA256 + 时间戳鉴权（防随意抓取与重放）
 客户端启动自动提权（UAC）；驱动/打印机安装改为回读系统状态校验
 支持多台打印机共享，按 RAW 端口号区分（9100 → /ipp/print/9100，9101 → /ipp/print/9101）
 服务端支持系统托盘常驻；服务安装/卸载会等待 SCM 状态，卸载可确认服务条目已移除
 使用说明：pdfium.dll 必须与 PrintServer.exe 同目录；Win7 需 KB2999226，
   否则 PDF 免驱不可用（自动降级为 PDL 直通，RAW 打印不受影响）
 自测：Debug 版支持 /cryptotest、/apitest、/tcptest、/svctest 命令行冒烟自测
